AIArchLab

Applied AI for organisations that get audited.

We put AI agents into production where audit, access control and rollback are not optional. Nothing is called delivered until someone else can re-run it and get the same result.

What we hold to

  • Governance is executable, not written.Policy becomes a check the system runs on itself. If it is only a document, it is not a control.
  • Evidence over claims.Every artefact ships with a re-runnable command, a hash and a read-back. Third parties verify it, not us.
  • Small pilot first.Nothing scales before it has run in production and survived an incident review.

Selected work

  • weirwright Executable change-control gates. Evidence in, verdict out.
  • works Finished work: governance tools and delivery systems, each with its verification record.
  • recruitflow-core Hiring workflow engine. Pure-function state machine with weighted scoring.
  • Splice Handoff Broker Handing a long-running agent task between runtimes without running it twice. Leases, fencing, audit record.
